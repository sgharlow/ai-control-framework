# AI Control Framework - Quick Reference

## Essential Commands

### Check if safe to continue (PowerShell)
```powershell
.\Run-Check.ps1 continue
```

### Check if safe to continue (Bash)
```bash
./run-check.sh continue
```

### Calculate Deployability Score
```powershell
.\Run-Check.ps1 drs
```

### Run all checks
```powershell
.\Run-Check.ps1 all
```
